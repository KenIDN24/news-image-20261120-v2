A one-page broadsheet of Friday 20 November 2026, drawn entirely by
program: a pictured lead on the first Trump–Xi–Putin summit in
Shenzhen, the World Court's genocide verdict against Myanmar, a
dotted world map with the day's fifteen flashpoints marked, and a
briefs grid covering the rest of the day.

`main.py` is pure Python 3 standard library — no Pillow, no network,
no randomness — and renders a deterministic 1024×1024 PNG to
`/output/entry.png`:

```sh
python3 main.py
```

Two runs produce byte-identical files. Sources for every story are
in [SOURCES.md](SOURCES.md).
